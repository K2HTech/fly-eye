# Bundled fonts

The Fly Eye desktop application bundles the following fonts so its operator UI
renders consistently without a network connection:

- **Saira Condensed** — Medium (500), SemiBold (600), Bold (700), and ExtraBold
  (800), sourced from the
  [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/sairacondensed).
- **IBM Plex Sans** — Regular (400), Medium (500), SemiBold (600), and Bold
  (700), sourced from the
  [IBM Plex repository](https://github.com/IBM/plex/tree/master/packages/plex-sans/fonts/complete/ttf).
- **IBM Plex Mono** — Regular (400), Medium (500), and SemiBold (600), sourced
  from the
  [IBM Plex repository](https://github.com/IBM/plex/tree/master/packages/plex-mono/fonts/complete/ttf).

Each typeface is distributed under the SIL Open Font License 1.1. Its license
text is stored beside the corresponding font files as `OFL.txt`.
